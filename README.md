## 🧠 Filosofía de Desarrollo

<div align="center">

| Principio | Cómo lo aplico |
|-----------|----------------|
| 🏗️ **Architecture first** | Diseño el sistema antes de escribir la primera línea |
| 🚀 **CI/CD desde día 1** | GitHub Actions configurado en el primer commit |
| 📦 **Deployment-ready** | Docker + health checks + variables de entorno desde el inicio |
| 📝 **Conventional Commits** | Historial limpio → versioning semántico automático |
| 🔍 **Observability** | Logs estructurados, health endpoints, métricas desde el arranque |
| 🔒 **Security by default** | Secrets en variables de entorno, nunca hardcodeados |
